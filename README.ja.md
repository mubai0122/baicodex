# BaiAgent / baicodex

[简体中文](README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md) · **日本語**

スマートフォン本体で動く Android AI エージェント。モデルへは直接接続し、ファイルの読み書き、コマンド実行、Linux の実行まで全部デバイス上で完結します。中継サーバーを一切挟まないので、会話・ファイル・API キーはすべてあなたの端末の中に残ります。

ただのチャット画面でもありません。「バックグラウンドを整理して」「明日の上海行きの切符を調べて」「このエラーを特定して」と言えば、画面を見て、手順に分解し、ツールを呼び、最後までやってから結果を返します。

パッケージ名 `b.ai`、minSdk 24（Android 7.0、targetSdk 34）、Kotlin + Jetpack Compose、単一 Activity、ABI は `arm64-v8a` / `armeabi-v7a`。

## 普通の AI アプリとの違い

- **本当に手を動かす。返事だけではない**：エージェントループがツール呼び出しを伴い、ファイル読み書き、shell 実行、Linux 実行、画面タップはすべて実際の実行で、結果はモデルに戻されて次の手順へ進む
- **権限は 3 段階から選択**：通常のアプリ権限だけでも使える（アクセシビリティ + ゼロ幅ファイルチャネル）、システムレベルの機能が要るなら Shizuku、完全に解放するなら Root。ツール側が自動で経路を選び、確認ダイアログに実際の経路を表示する
- **ゼロ幅ファイルチャネル**：`read_file` / `write_file` / `make_dir` / `delete_file` は root なしで他アプリの data ディレクトリまで届く。`exec_shell` は元のパスを使うのでこの変換の影響を受けない
- **データは外に出ない**：セッション、ペルソナ、スキル、使用量はすべてローカル SQLite に保存され、クラウドには上がらない。外部通信するのは設定したモデル API と、自分で使った検索・12306 だけ
- **分解して書き換えられる**：モデル、検索プロバイダ、ツール権限、スキルパック、思考レベルはすべて設定で差し替え可能。ソースを直して自分でビルドできる

## 3 つの実行モード

| モード | 必要なもの | できること |
|---|---|---|
| 通常のアプリ権限 | インストールすればすぐ | 会話、ファイル読み書き、`exec_shell`（アプリ権限）、アクセシビリティによるスクリーンショット / タップ / スワイプ / 入力、ゼロ幅チャネルでの data 読み取り、ネットワークツール |
| Shizuku | Shizuku を入れて許可 | root なしでシステムレベルの shell、`uiautomator dump`、`screencap`、バックグラウンドアプリ管理、data の深い読み取り |
| Root（su） | 端末が root 済み | システムディレクトリの読み書き、pm によるサイレントインストール / アンインストール、グローバル操作。ツール側は su を優先 |

3 つは排他的なスイッチではなく、同じツール表の下にある 3 本のチャネルです。いつでも切り替えられ、次の呼び出しから反映されます。

## 機能

### モデルと会話

- 複数のモデルプロファイル：1 件 = プロバイダ + Base URL + キー + モデル + 能力フラグ（vision / tool calling / reasoning）。いつでも切替でき、OpenAI 互換 API なら接続可能
- 思考レベル（low / medium / high）、最大モード、temperature と追加パラメータ。SSE ストリーミング出力、思考ブロックは折りたためる
- メッセージ分岐：再生成 / 編集して再送しても古い回答は消えず、2 本目の分岐として伸びる。チャット内の `‹ 1/2 ›` で行き来できる（メッセージツリー、DB v11）
- 永続メモリ：長期記憶に値するとモデルが判断した好みや結論を「メモリ」に保存。ドロワーから 1 件ずつ削除でき、削除しない限り毎ターンシステムプロンプトと一緒に送られる（DB v12）
- コンテキスト圧縮：ウィンドウ比率（既定 70%）と未圧縮メッセージ数の 2 つのしきい値で発動し、長い会話でもウィンドウを溢れさせない
- 音声入力で話してそのまま送信。各回答の下に token 数、tok/s、最初の応答までの時間、プロバイダ、モデルを表示

### ツールと実行

- 内蔵ツール：ファイル 4 種、`exec_shell`、`exec_linux`、`screen`（画面操作）、`web_search`、12306 の空席 / 乗り継ぎ / 停車駅、メモリ書き込み、スケジュールタスク
- 検索プロバイダは 3 社から選択：Tavily、Bing、Google CSE。キーは自分で入力し、未設定なら検索ツールをモデルに渡さない
- 実行チャネルは 3 段階（通常 / Shizuku / Root）。ツール側が自動で経路を選び、ダイアログに実際の経路を表示
- ツール権限を 1 件ずつ設定：確認 / 許可 / 拒否。高リスクのツールは別途マーク。ミニマルモードでは 5 つのツールだけを残して弱いモデル向けの保険にする
- プランモード：読み取り専用コマンドは通し、`exec_shell` 内の書き込みは一律で拒否。「ちょっと見るだけ」が「もう消した」にならないようにする
- カスタムスキルパック：自分でツールを書いて入れれば、モデルが説明を読んで選ぶ
- MCP クライアント：JSON-RPC 2.0 over HTTP。接続したサーバーの機能はツール表と @ パネルに統合され、ツール名は `mcp_サーバー_機能` の接頭辞になる

### 画面操作

- アクセシビリティサービスへ直接接続：ノードツリーの dump、タップ、長押し、スワイプ、入力、キーイベント、アプリ起動、アプリ一覧。Shizuku がなくてもスクリーンショットは撮れる
- 多段階のタスク中は画面上部に操作カプセルが常駐し、今どの手順をやっているかを表示。指示が終わると自動で畳まれる
- 画像とノードツリーの 2 経路：モデルはスクリーンショットも、コントロールのテキストと座標も読める。確信が持てなければ経路を切り替える

### 内蔵 Linux

- proot + 自己解凍 rootfs。初回起動時に自動で入り、root 不要でホスト側を一切触らない
- `apt` で依存を入れ、`gcc` / `node` で直接ビルド。C / C++ / Rust / Go がスマホ上で動く
- Android のファイルシステムと双方向にやり取りでき、`/sdcard` と `/storage` をそのままマウント
- サンドボックス分離。壊してもいつでもリセットでき、システムを汚さない

### UI とカスタマイズ

- セッション：ピン留め、長押しで複数選択、名前変更 / 削除、セッションをまたぐお気に入り、セッションごとの下書き
- ペルソナカード（人設 / シナリオ / 例示会話 / 第一声 / 紐付けモデル）とカスタムスキルパック
- 外観：単色 / 柔らかなグラデーション / ドット背景、リキッドグラスのカードとボトムバー、質感のあるボタン、全体の文字サイズ、ダークモード
- UI は 5 言語：简体中文 / 繁體中文 / English / 日本語 / Français

### データと配布

- セッション、ペルソナ、スキル、ワークスペースの紐付け、使用量台帳はすべてローカル SQLite（`bai.db` + `bai_stat.db` の 2 本）に保存。クラウド経由なし
- 使用統計：合計 / カテゴリ別 / モデル別 + 日付グリッド。入力・出力・キャッシュの 3 つの単価を入れれば実コストが出る
- データベース全体のバックアップと復元：DB / 設定 / データルートの小ファイル / アイコンを 1 つの zip に書き出し、取り込み後の次回起動で自動的に差し替え
- アプリ内アップデート確認（`agent.ai.baiccb.cn/api/update`）。直リンクからダウンロードしてシステムのインストーラを起動

## FAQ

**root は必要ですか？**

いいえ。通常のアプリ権限でほとんどの機能が使えます。システムレベルの shell が必要なら Shizuku（Android 11 以上を推奨）、システムディレクトリを書き換えるなら root が必要です。

**本当に無料ですか？**

はい。GPL-3.0 のオープンソースで、アプリ内課金・サブスク・広告・回数制限はありません。自分でビルドすることもできます。

**データはアップロードされますか？**

いいえ。会話、ファイル、キーはすべて端末上にあります。初回起動時に同意画面が出て、同意した場合のみ匿名の利用統計を送信します。拒否しても機能に影響はありません。

**対応している Android バージョンは？**

Android 7.0（API 24）以上、targetSdk 34、ビルドは SDK 37。APK には `arm64-v8a` と `armeabi-v7a` が含まれます。

## ビルド

JDK 17 と Android SDK 37 が必要です（`local.properties` に `sdk.dir` を記述）。

```bash
./gradlew assembleDebug     # debug：難読化なし、文字列暗号化なし、ログは読める
./gradlew assembleRelease   # release：R8 難読化 + リソース縮小 + 文字列暗号化
```

release では次の 3 つを行います。設定は `app/proguard-rules.pro` と `app/build.gradle.kts` にあります：

1. **R8 難読化**：`MainActivity`、マニフェストのエントリ、サードパーティ製ライブラリの必須項目以外はすべて改名。辞書は自作の短い名前（`app/obfuscation_dict.txt`）で、`-repackageclasses` によりパッケージ名も消す
2. **文字列暗号化**：StringFog、アルゴリズムは AES、文字列ごとに独立したランダムキー
3. **ログ除去**：release では `Log` / `println` はすべて空文になる

文字列暗号化のキーはリポジトリに入れず、`local.properties` から読みます：

```properties
stringfog.key=自分のキー
```

未設定でもビルドは通りますが、プレースホルダ文字列にフォールバックします（プレースホルダは暗号化なしと同じなので、それで配布しないでください）。

```
app/src/main/kotlin/b/ai/
  agent/    Agent ループとツール定義

  exec/     shell / root / shizuku チャネル、アクセシビリティ、スケジュールタスク

app/src/main/assets/linux/   内蔵 Ubuntu の rootfs と proot
scripts/   ビルドと素材のスクリプト
```
