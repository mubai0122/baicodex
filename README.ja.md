# BaiAgent / baicodex

[简体中文](README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md) · **日本語**

**Android を自分の身体として扱う AI Agent。** ただのチャットではありません。「バックグラウンドを整理して」「このエラーを特定して」「スクリプトを書いて実行して」と言えば、画面を見て、手順に分解し、ツールを呼び、コードを書き、ビルドまでやって、結果を返します。すべて実際に実行します。デモではありません。

モデルへは直接接続。会話・ファイル・キーはすべて端末内に残り、中継サーバーを一切挟みません。

Rust コア 1 本、フロントエンド 3 種：**Android**、**Windows**、**ターミナル**。

- 公式サイト：<https://agent.ai.baiccb.cn>
- ダウンロード：<https://github.com/mubai0122/baicodex/releases/latest>
- ライセンス：AGPL-3.0、課金・広告・回数制限なし。クローズドソース製品への組み込みや SaaS 提供には商用ライセンスが必要

## ハイライト

1. **Android 上の本物の Agent、3 段階の権限で最大限に**
   通常のアプリ権限で入れたそのまま使え、Shizuku を入れて Root なしでシステム級の能力を獲得、Root で完全に解放。3 段階は排他のスイッチではなく、1 つのツール表の下にある 3 本のチャネルです。ツール側が自動で経路を選び、ポップアップに今回どれを使ったかを表示します。
   <sub>通常権限のゼロ幅ファイルチャネル（任意のアプリの data を読み書き）はすべての機種で使えるわけではありません。導入後にアプリ内で実測してください。</sub>

2. **内蔵の仮想 Linux サンドボックス、本当に動く**
   proot + 自己展開する Ubuntu 24.04 rootfs をアプリのプライベートディレクトリに展開。ホストを汚さず、壊れたらリセットすればきれいに戻ります。apt で依存を入れ、gcc / node でそのままコンパイル、C / C++ / Rust / Go が動きます。Windows の exe も別リポジトリ不要——arm64 のアーカイブに `box64` と `wine 9.0` があるので入れて動かせます。GUI プログラムは Xvfb / VNC を足して画面を見ます。スマホの性能は限られるので Android Studio のような重量級 IDE は構想レベルですが、「動く」こと自体は本当です。
   <sub>guest プログラムの実行には Root / Shizuku チャネルが必要です（targetSdk 34 では SELinux がアプリのプライベートディレクトリからの execve を禁止）。</sub>

3. **マルチエージェント、切り替え可能**
   キャラクターカードで人格・シナリオ・開始メッセージ・束縛モデルを切り替えられます。カードを替えることは人格と話し方を替えること。A2A で他の Agent と作業を投げ合えます。
   <sub>3.1 大肥魚デスクトップペット：アプリ内に常駐する浮遊キャラクター。アニメーションは 30fps に間引かれ、開いただけで画面全体が重くなることはありません。</sub>

4. **徹底した安全性**
   認証情報は AES-256-GCM で保存し、デバイスキーは Android Keystore（TEE / StrongBox）で包まれ、平文がハードウェアの外に出ません。モデルはキーの原文を読めず、外向けの出口はすべてマスクされます。`sk-` / `ghp_` / PEM / Bearer はログ書き込み、モデルへのツール出力の返却、診断パッケージの書き出しの前にすべて消されます。

5. **画面操作、Root 不要**
   アクセシビリティ直結：ノードツリーの dump、タップ、長押し、スワイプ、入力、キー送信、アプリ起動、アプリ一覧。スクリーンショットは Shizuku なしでも取れます。視覚とノードツリーの 2 経路で、モデルが判断しづらいときは切り替えます。

6. **MCP の遊び場が広い**
   標準 JSON-RPC 2.0 over HTTP と REST ブリッジの両方に対応。Termux の termux-mcp、ローカルの mt-mcp、任意の標準 MCP サーバーに直接つながります。逆に、他のエージェントが baicodex を MCP として使うこともできます。

7. **SSH / GitHub / Skill、拡張性は最大**
   SSH は 8 点セット（接続 / 一覧 / 読み / 書き / 昇格 / 実行 / ダウンロード / アップロード）。sudo のパスワードはツールが `sudo -S` に流し込み、コマンドラインには出ません。GitHub スキルパッケージは REST API でリポジトリ、issue / PR、ファイル読み取り、単一ファイルのコミットまで。独自プロトコルの skill には専用 JS エンジン（QuickJS）、汎用 skill もそのまま使えます。

8. **コンテキスト圧縮、知能も記憶も失わない**
   要約の切断点は「ツール呼び出しとその結果の間」という安全な境界まで戻し、結論とファイルパスは必ず残します。ウィンドウ比率と件数の両方のしきい値を超えたときだけ発動し、15% も節約できないなら実行しません。長期記憶は別ストアに保存され、圧縮で消えません。

9. **長期記憶**
   モデル自身が長期で覚える価値があると判断した好みや結論を「記憶」に保存。毎ターンシステムプロンプトと一緒に渡され、サイドバーから 1 件ずつ削除できます。

10. **技術スタックの幅**
    Rust コア + C++ ネイティブ層 + Kotlin / Compose UI + TypeScript / WebView2 デスクトップ。1 つのコアで 3 プラットフォーム。

## 普通の AI アプリとの違い

- **本当に手を動かす、返事だけではない**：Agent ループがツール呼び出しを伴い、ファイル読み書き、shell 実行、Linux 実行、画面タップはすべて実際に実行され、結果がモデルに戻されて次の段へ進む
- **権限 3 段階を自分で選ぶ**：通常のアプリ権限でほぼ使える（アクセシビリティ + ゼロ幅ファイルチャネル）、システム級が必要なら Shizuku、完全に解放するなら Root。経路選択はツール内部で自動、ポップアップに実際の経路を表示
- **ゼロ幅バイパス**：`read_file` / `write_file` / `make_dir` / `delete_file` が制限ディレクトリを仮想パスに写像し、Root なしで他アプリの data ディレクトリに届く。`exec_shell` は元のパスのままで、この変換の影響を受けない
- **データは外に出ない**：会話・キャラクター・スキル・使用量はすべてローカル SQLite、クラウドなし。外部に出るのは設定したモデルエンドポイントと、自分で使った検索・12306 だけ
- **1 つのコアで多端末**：Rust コアが Android・Windows・ターミナルを同時に支え、UI は別々に書くがロジックは分岐しない
- **分解して改造できる**：モデル、検索ソース、ツール権限、スキルパッケージ、思考レベルはすべて設定で変更可能。ソースを直して自分でビルドしてもいい

## 機能

### モデルと会話

- 複数のモデル設定：1 行 = プロバイダ + Base URL + キー + モデル + 能力フラグ（視覚 / ツール呼び出し / 推論）。いつでも切り替え可能で、OpenAI 互換なら接続できる
- 思考レベル（low / medium / high）、最大モード、温度と追加パラメータ。SSE ストリーミングで本文、思考ブロック（`reasoning_content`）、`tool_calls` の引数まで受信しながら描画し、思考ブロックは折りたためる。サーバーが `stream=true` を無視して 1 パケットで返した場合も、エラーにせずパースを切り替える
- メッセージ分岐：再生成・編集して再送しても古い回答は消えず、2 本目の枝として伸びる。チャット内で `‹ 1/2 ›` で行き来できる（DB v11 メッセージツリー）
- 永続記憶：モデルが長期保存に値すると判断した好みや結論を「記憶」に保存。サイドバーから 1 件ずつ削除でき、削除しない限り毎ターンのシステムプロンプトに載る（DB v12）
- 記憶を失わないコンテキスト圧縮：ウィンドウ比率（既定 70%）と未圧縮件数の両方のしきい値で発動。切断点は「ツール呼び出しとその結果の間」という安全な境界まで戻す（途中で切るとリクエストが不正になる）。要約には結論と変更したファイルパスを必ず残し、15% も節約できないなら実行しない。長期記憶は別ストアにあり、要約と一緒に消えない
- 音声入力は話し終えたらそのまま送信。各回答の下に token、tok/s、初回応答時間、プロバイダ、モデルを表示

### ツールと実行

- 内蔵ツール：ファイル 5 点セット（読み / 書き / 部分編集 / ディレクトリ作成 / 削除）、`exec_shell`、`linux_shell`、`screen`（画面操作）、`browser`、`http_fetch`、`apk`（署名証明書と dex の調査）、`js`（QuickJS でスクリプト実行、新しいツールの登録も可能）、12306 の残席 / 乗換 / 停車駅、記憶の書き込み、定期タスク
- SSH 8 点セット：`ssh_connect` / `ssh_ls` / `ssh_read` / `ssh_write` / `ssh_sudo` / `ssh_exec` / `ssh_get` / `ssh_put`。ホストと認証情報は一度保存すれば再利用。内蔵 Ubuntu に openssh-client がなければ自動で導入。sudo のパスワードは `sudo -S` に流し込み、コマンドには書きません
- GitHub スキルパッケージ：REST API 経由でリポジトリ / issue / PR の調査、リポジトリ内ファイルの読み取り、単一ファイルの新規作成・更新。トークンは `$secret.github_token` から供給され、ローカル git も gh も不要
- Web 取得の 2 経路：`web_search`（Tavily・Bing・Google CSE から選択、キーは自分で設定。未選択ならモデルに検索ツールを渡さない）、`http_fetch`（生の HTTP、ステータスコード + 本文先頭 8000 文字を返す）
- 内蔵ブラウザ：`browser` は本物の WebView でクローラーではない。読むのはレンダリング後のページ——`open` で開いて本文を返し、`text` / `links` / `find` で内容取得・リンク列挙・文字からの要素特定、`click` / `input` / `scroll` で文字指定のクリック・入力・スクロール、`eval` で JS を直接実行、他に `back` / `forward` / `reload` / `url` / `close`。ログインが必要なページや JS で描画されるページはこの経路で扱う
- 実行チャネル 3 段階（通常 / Shizuku / Root）。ツール内部で自動選択し、ポップアップに実際の経路を表示
- ツール権限を 1 件ずつ設定：確認 / 許可 / 拒否。危険度の高いツールは別途表示。最小モードでは 5 つのツールだけ残し、弱いモデルでも破綻しない
- プランモード：読み取り専用コマンドは通し、`exec_shell` 内の書き込みは一律で拒否。「ちょっと見るだけ」が「もう消した」にならない
- カスタムスキルパッケージ：自作ツールを入れると、モデルが説明を見て自分で選ぶ
- MCP クライアント：標準 JSON-RPC 2.0 over HTTP（`tools/list` + `tools/call`）に加え REST ブリッジ（`GET /tools` + `run`）。Termux の termux-mcp、ローカルの mt-mcp、任意の標準 MCP サーバーが直接つながる。取り込んだ機能はツール表と @ パネルに統合され、名前の接頭辞は `mcp_サーバー_機能`
- ワークフロー：複数ステップのタスクを 1 本の流れにし、各ステップをサブエージェントが実行。ステップ間でコンテキストは共有しない
- A2A：1.0 仕様に沿って SendMessage / GetTask / ListTasks / CancelTask を実装。メソッド名もステータスコードも仕様どおりで、他のエージェントから仕事を振られ、こちらからも振れる

### 画面操作

- アクセシビリティ直結：ノードツリーの dump、タップ、長押し、スワイプ、入力、キー送信、アプリ起動、アプリ一覧。Shizuku なしでもスクリーンショットが取れる
- 複数ステップのタスクでは画面上部に操作カプセルが常駐し、このステップが何をしているかを表示。1 つの指示が終わると自動で引っ込む
- 視覚とノードツリーの 2 経路：スクリーンショットも、ウィジェットのテキストと座標も読める。判断しづらいときはもう一方に切り替える

### 内蔵 Linux

- **仮想サンドボックス**：proot + 自己展開する Ubuntu 24.04 rootfs をアプリのプライベートディレクトリに。ホストは汚さず、壊れたらリセットでまっさら
- `apt` で依存を導入し、`gcc` / `node` でそのままコンパイル。C / C++ / Rust / Go がスマホで動く。arm64 の noble アーカイブに `box64` と `wine 9.0` があるので Windows exe も動き、GUI プログラムは Xvfb / VNC を追加して画面を見る
- Android のファイルシステムと双方向に連携。`/sdcard` と `/storage` をそのままマウント
- パスサンドボックスと合わせて二重の関門：サンドボックスが「このパスを触ってよいか」を判断し（機密のシステムファイル、`..`、シンボリックリンクは実行前に止める）、proot が「壊してもシステムに傷がつかない」ことを担保する
- **現状**：guest プログラムの実行には Root / Shizuku チャネルが必要（targetSdk 34 では SELinux がアプリのプライベートディレクトリからの `execve` を禁止）

### デスクトップ（Windows）

- ボーダーレスウィンドウ + DWM リキッドグラス + WebView2 描画面。UI は `desktop/web` の TypeScript + Vite コード
- スマホと同じ Rust コア、同じバージョン番号、同じツール表と設定構造

### 見た目とカスタマイズ

- **外観マテリアル**：単色 / 柔らかなグラデーション / ドット背景、独自壁紙も可（切り替え時はサムネイルを先に出してから実画像を読み込むので、コールドスタートでも白く光らない）
- **リキッドグラス**：カード、入力欄、フローティングタブバー、ダイアログが同じガラス素材を使う。まとめてオフにして白いカードにも戻せる。質感ボタンという別スタイルもあり、ガラスとは排他
- **レイアウトと文字サイズ**：全体の文字サイズは独立して調整。吹き出しは角丸とカプセルの 2 レイアウト。チャットのアバター表示はオフにできる
- **ダークモード**：切り替え可能。ガラス、壁紙、文字色も一緒に変わる
- **キャラクターカード**：人格、シナリオ、例示会話、開始メッセージ、束縛モデル。チャットのアバターは「現在のカードに追従」か自分の画像を選択
- **デスクトップペット**：アプリ内に常駐する浮遊キャラクター。アニメーションは 30fps に間引き、開いただけでページが重くならない
- **フローティングチャット**：他のアプリの上で直接チャット。幅・高さ・文字サイズ・透明度・位置をすべてドラッグでき、メイン画面と同じセッションを共有
- **セッション管理**：ピン留め、長押しで複数選択、名前変更 / 削除、セッションをまたぐお気に入り、セッションごとの下書き
- **プラグインストア**：閲覧、インストール、アップロード、バージョン履歴、コメント、いいねとお気に入り
- **5 言語 UI**：簡体字中国語 / 繁体字中国語 / English / 日本語 / Français

### データとリリース

- 会話、キャラクター、スキル、ワークスペース紐付け、使用量台帳はすべてローカル SQLite（`bai.db` + `bai_stat.db` の 2 DB）。クラウドなし
- 使用統計：総量 / カテゴリ / モデル別に加えて日付ヒートマップ。入力・出力・キャッシュの 3 単価を入力すれば金額まで出る
- 全体バックアップと復元：DB / 設定 / データルートの小ファイル / アバターを 1 ファイルに書き出し、取り込むと次回起動時に置き換え
- アプリ内アップデート確認（`agent.ai.baiccb.cn/api/update`）。直リンクでダウンロードし、システムのインストーラを起動

## 3 つの実行モード（Android）

| モード | 必要なもの | できること |
|---|---|---|
| 通常のアプリ権限 | 入れるだけ | 会話、ファイル読み書き、`exec_shell`（アプリ権限）、アクセシビリティでのスクリーンショット / タップ / スワイプ / 入力、data のゼロ幅読み取り、ネットワークツール |
| Shizuku | Shizuku を入れて許可 | Root なしでシステム級 shell、`uiautomator dump`、`screencap`、バックグラウンドアプリ管理、data の深い読み取り |
| Root（su） | root 済み端末 | システムディレクトリの読み書き、pm によるサイレントインストール / アンインストール、全体操作。ツールは su を優先 |

3 つのモードは排他のスイッチではなく、1 つのツール表の下にある 3 本のチャネル。いつでも切り替えられ、次の呼び出しから有効になります。

<sub>注：通常権限でのゼロ幅ファイルチャネルは機種 / OS ビルドに依存し、使える機種と使えない機種があります。アプリ内で実測してください。内蔵 Linux サンドボックスは Root / Shizuku チャネルが必要です。</sub>

## セキュリティ

3 層のキー（Keystore で包んだキー + HKDF の半キー + データキー）。認証情報は AES-256-GCM で保存（ファイル先頭のマジックは `baicodexencryption`）。API キー、アカウント、SSH と GitHub の認証情報、スキルの秘密はそれぞれ別の暗号文として保存。モデルはキーの原文を読めず、外向けの出口はすべてマスクされます。ロック解除前は認証情報が平文 JSON + 0600 に退避しますが、UI は「未暗号化」と明示し、安全なふりはしません。

## FAQ

**Root は必要ですか？**
いいえ。通常のアプリ権限でほとんどの機能が使えます。システム級の shell が欲しければ Shizuku（Android 11 以上を推奨）、システムディレクトリを書き換えるなら Root。内蔵 Linux サンドボックスだけは例外で、中のプログラムを実行するには Root / Shizuku チャネルが必要です。

**本当に無料ですか？**
はい。AGPL-3.0 のオープンソースで、課金・サブスク・広告・回数制限はありません。自分でビルドしても構いません。クローズドソース製品への組み込みや、AGPL のソース公開義務を免除した SaaS 提供には商用ライセンスが必要です（下記「ライセンス」参照）。

**データはアップロードされますか？**
されません。会話、ファイル、キーはすべて端末内です。初回起動時に同意画面があり、同意した場合のみ匿名の利用統計を送信します。拒否しても機能は変わりません。

**対応 Android バージョンは？**
Android 7.0（API 24）以上、targetSdk 34、ビルドは SDK 37。APK は `arm64-v8a` と `armeabi-v7a` を含みます。

## 開発者向け

### 拡張方法

- **スキルパッケージ（Skill）**：自作ツールを入れるとモデルが説明から選ぶ。専用 JS エンジン（QuickJS）でスクリプト実行も新ツール登録も可能
- **プラグインストア**：閲覧、インストール、アップロード、バージョン履歴、コメント、いいねとお気に入り
- **MCP**：標準 JSON-RPC 2.0 over HTTP と REST ブリッジの 2 経路。termux-mcp / mt-mcp / 任意の標準 MCP サーバーが直接つながる
- **A2A**：1.0 仕様の SendMessage / GetTask / ListTasks / CancelTask を実装し、他の Agent と作業を投げ合う
- **ワークフロー**：複数ステップのタスクを 1 本の流れにし、各ステップをサブエージェントが実行


**Android**

JDK 17 と Android SDK 37 が必要です（`local.properties` に `sdk.dir` を記述）。

```bash
./gradlew assembleDebug     # debug：難読化なし、暗号化なし、ログは読める
```

文字列暗号化のキーはリポジトリに入れず、`local.properties` から読みます：

```properties
stringfog.key=自分のキー
baicodex.aes.key=認証情報暗号化のシード
```

未設定でもビルドできますが、プレースホルダ文字列に退避します（プレースホルダは暗号化なしと同じ。リリースに使わないこと）。
