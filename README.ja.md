# BaiAgent / baicodex

[简体中文](README.md) · [English](README.en.md) · [繁體中文](README.zh-TW.md) · **日本語**

**Android 向け Agent（エージェント）です。** ただのチャットではありません。「アプリを作ってビルドして」「このエラーを特定して」「スクリプトを書いて実行して」と言うだけで、画面を見て、手順を分解し、ツールを呼び出し、コードを書き、コンパイル・ビルドし、結果をあなたに返します。

**オープンソースで手軽**：インストール直後に動作し、PC は不要です。ネイティブの **MCP** と **米家（Xiaomi スマートホーム）** エコシステムに対応し、継続的にメンテナンスされています。

**プライバシー**：モデルは直接接続。会話・ファイル・キーはすべて端末内に保存され、中継サーバーを経由しません。

- 公式サイト：<https://agent.ai.baiccb.cn>
- チュートリアル（AndroidAgent を使いこなす）：<https://agent.ai.baiccb.cn/docs/>

## 特徴

1. **Android Agent、PC 不要で動作**
   通常アプリとしてインストールするだけで使えます。Shizuku を使えば Root なしでシステムレベルの権限を取得、Root なら全機能を解放。3 段階は排他的な切り替えではなく、1 つのツールテーブルの下で 3 つの経路を自動的に選択します。
   <sub>通常権限でのゼロ幅ファイルチャネル（任意アプリの data を読み書き）はすべての機種で動作するわけではありません。インストール後にアプリ内で実際に確認してください。</sub>

2. **内蔵 Linux サンドボックス、実際に動く**
   proot + 自己展開型の Ubuntu 24.04 rootfs をアプリのプライベート領域に展開し、ホストを壊しません。壊してもリセットすれば綺麗な状態に。`apt` で依存を入れ、gcc/node で直接コンパイル。C/C++/Rust/Go が動き、Windows の exe も動きます。理論上は Android Studio も動かせます。

3. **マルチエージェント、切り替え可能**
   キャラクターカードで人格・シナリオ・冒頭の挨拶・紐付けるモデルを切り替え。キャラ変更＝人格と話し方ごと切り替わることです。複数プロンプトの切り替えに対応。

4. **徹底したセキュリティ**
   認証情報は保存時に暗号化。デバイスキーは Android Keystore でラップされ、平文はハードウェア外に出ません。モデルはキーの原文を読めません。出力は統一的にマスキングされ、高強度暗号化を有効にすると `sk-`/`ghp_`/PEM/Bearer はログ記録・モデルへの再投入・診断パッケージのエクスポート前にすべて除去されます。

5. **画面操作、Root 不要**
   AccessibilityService に直接接続：ノードツリーのダンプ、タップ、長押し、スワイプ、入力、キー操作、アプリ起動、アプリ一覧。Shizuku も Root も不要で動作します。

6. **MCP の遊び方が豊富**
   標準 JSON-RPC 2.0 over HTTP + REST ブリッジ。Termux の termux-mcp など、あらゆる標準 MCP サービスに直接接続。逆に、他者が baicodex を MCP として使うこともできます。

7. **SSH / GitHub / Skill、拡張性は最大級**
   SSH ツール一式、GitHub スキルパックツール一式。独自プロトコルの skill（遊び心満載）も汎用プロトコルの skill も解析に対応。

8. **コンテキスト圧縮、賢さも記憶も失わない**
   セーフティ境界が結論やファイルパスなどの重要情報を強制的に保持。ウィンドウ比率＋メッセージ数の閾値で発火。長期記憶は個別に保存され、圧縮しても消えません。

9. **長期記憶**
   モデルが「覚える価値がある」と判断した好みや結論を「記憶」に保存。各ターンのシステムプロンプトに付与され、サイドバーで 1 件ずつ管理できます。

10. **広い技術スタック**
    Rust コア + C++ ネイティブ層 + Kotlin / Compose UI + TypeScript / WebView2 デスクトップ、npmCI 対応。

11. **米家・NetEase Cloud Music・LAN 連携はすべてネイティブ実装**
    米家は Xiaomi スマートホームを LAN・クラウド経由で操作。NetEase Cloud Music はログイン後に米家と連携可能。同じ Wi-Fi の複数端末はペアリングコードのハンドシェイク後にチームを組み、ファイルを送り合えます。

## 普通の AI アプリとの違い

- **実際に動く、話すだけじゃない**：Agent のツール呼び出しは、ファイルの読み書き・コマンド実行・画面タップなどすべて実実行で、結果はモデルに渡されて次のステップへ。
- **権限は 3 段階から選択**：通常ユーザーでも大部分の機能を解放。Shizuku と Root で全機能を引き出せます。
- **data 読み取り**：対応端末では、制限されたディレクトリを仮想パスにマッピングして data ディレクトリへ到達。
- **データは外に出ない**：会話・キャラクター・スキル・利用状況はすべてローカル SQLite に保存。
- **端末内推論**：スマホ GPU で大規模モデルを動かせます。`llama` 対応、完全にローカル。

## 機能

### モデルと会話

- 複数モデルの設定切り替え：プロバイダ + BaseURL + Key + モデル + ケイパビリティフラグ。OpenAI 互換 API なら何でも接続可能。
- 推論レベル、最大モード、温度、追加パラメータ。SSE ストリーミング出力、思考ブロックは折りたたみ可能。
- メッセージ分岐：再生成・編集して再送でも古い回答は削除されず、切り替え可能。
- 音声入力：話し終わったらそのまま送信。
- 回答下部に token、tok/s、初回応答時間、プロバイダ、モデルなどを表示可能。
- 現在時刻・バッテリー・位置・通知・端末の利用時間を注入でき、あなたをより理解します。

### ツールと実行
### デフォルトだけでなく、自作もサポート

- ファイル操作：読み、書き、部分編集、ディレクトリ作成、削除
- コマンド：exec_shell、linux_shell、画面操作、ブラウザ、ネットワーク、アプリ逆アセンブル、QuickJS、12306 チケット検索、定时タスク
- SSH：接続、一覧、読み取り、書き込み、権限昇格実行、コマンド実行、ダウンロード、アップロード。認証情報は再利用可能。
- GitHub：リポジトリ・issue・PR の検索、リポジトリファイルの読み取り、単一ファイルの作成・更新、コミットなど。
- Web：マルチエンジン検索、サイト内容の表示、直接 HTTP
- 内蔵ブラウザ：BrowserWebView がレンダリング済みページを読み取り、本文取得・内容抽出・リンク一覧・テキストでのタップ・フォーム入力・ページ送り・JS 実行・認証通過に対応。
- ツール権限設定：確認する / 許可 / 拒否
- プランモード：読み取り専用コマンドのみ許可、ファイル操作は不可、計画の監査出力は許可。
- カスタムスキルパック：モデルがあなたのためにスキルパックを書きます。
- ワークフロー：複数ステップのタスクを複数ストリームで並列実行。
- A2A：他の Agent との相互接続に対応。

### 米家とスマートホーム

- ツール：`mijia_devices`、`mijia_scan`、`mijia_read`、`mijia_write`、`mijia_action`

### ミュージック

- ツール：`music_platforms`、`music_login`（`verify` / `sms` / `code`）

*米家とツールを共有：1 文で「曲を流す → コードを書く → リビングのエアコンを 26 度にする」ができます。*

### LAN チームコラボレーション

- UDP ブロードキャストによる発見、ペアリングコードのハンドシェイク
- ペアリング済み端末の生存確認
- LAN 設定
- `lan` ツール：状態確認、受付サービスの開始、スキャン、ペアリング、解除、相手の能力確認、タスクの割り当て・キャンセル
- 同じ Wi-Fi の複数端末でファイル送受信。ポートと並列数は設定可能。

### 画面操作

- AccessibilityService に直接接続し、画面を操作可能。
- マルチステップ実行中は画面上部に操作カプセルが常駐。
- 視覚ノードツリーのデュアルパス：スクリーンショットを見ることも、コントロールのテキストと座標を読むこともできます。

### 内蔵 Linux

- **仮想サンドボックス**：ホスト上では動かないので、`rm /*` も怖くありません。
- Android ファイルシステムと双方向で連携、追加の監査確認も可能。

### UI とパーソナライズ

- **外観マテリアル**：単色 / ソフトグラデーション / ドットマトリクス背景、カスタム壁紙
- **リキッドガラス**：カード、入力欄、フローティングドック、ポップアップがリキッドガラスに対応
- **レイアウトとフォントサイズ**：フォントなどをカスタマイズ可能
- **ダークモード**：カスタムテーマと配色に対応
- **デスクトップペット**：ぽっちゃりお魚、ovo
- **フローティングチャットウィンドウ**：他のアプリの上で直接チャット、スタイル設定可能
- **セッション管理**：トップ固定、長押しで複数選択、名前変更、削除、セッション横断のお気に入り、セッションごとの下書き
- **プラグインプラザ**：閲覧、インストール、アップロード、バージョン履歴、コメント
- **5 言語**：简体中文 / 繁體中文 / English / 日本語 / Français

### データと公開

- ローカルの SQLite デュアルデータベース。エンドツーエンド暗号化のクラウドバックアップを開発中
- 利用統計：合計、金額＋日付ヒートマップ、グラフ
- データベース全体のバックアップと復元：暗号化バックアップと復元に対応

## 3 つの実行モード（Android）

| モード | 必要なもの | できること |
|---|---|---|
| 通常アプリ権限 | インストール直後から使用可能 | チャット、ファイル読み書き、コマンド実行、画面操作、ゼロ幅での data 読み取り、ネットワークツールなど |
| Shizuku | Shizuku の認可 | システムレベルの shell、`uiautomator dump`、`screencap`、バックグラウンドアプリ管理、data の深い読み取り |
| Root（su） | 端末が root 済み | システムディレクトリの読み書き、pm によるサイレントインストール・アンインストール、全体操作。ツール内部は su を優先 |

## セキュリティ

最大 3 層のキー、認証情報は AES-256-GCM で暗号化。API Key、アカウント、SSH・GitHub の認証情報、スキルのシークレットはすべて暗号文で保存。モデルはキーを読み取れず、出力のマスキングにも対応しています。

```
app/src/main/kotlin/b/ai/   Android UI とプラットフォーム層（agent / core / device / native / net / ui）

.work/script/               ビルド・リリーススクリプト（このディレクトリはリポジトリに含めません。クローン後に各自用意）
```
