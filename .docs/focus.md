# Focus

## 事实
- [用户明说] 项目 BaiAgent，包名 b.ai，Kotlin + Jetpack Compose，minSdk 24，compileSdk 36
- [用户明说] 定位：设备本地 AI Agent，OpenAI Chat Completions + function calling 驱动
- [用户明说] 工具集最小化：read_file / write_file / delete_file / exec_shell
- [用户明说] 三档权限：普通用户（含零宽路径）/ Shizuku / root，工具内部自动选路，弹窗标注实际路径
- [用户明说] exec_shell 权限不足直接报错，不自动降级重试
- [用户明说] 工具调用逐个弹窗串行确认，按钮：同意/拒绝/永久同意/永久拒绝
- [用户明说] 不内置模型列表，点“获取模型”请求 /models 解析 data[].id，失败保留手动填写
- [用户明说] 视觉：浅灰 + 白背景，状态栏与导航条透明，简洁克制
