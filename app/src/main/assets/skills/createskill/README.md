# 做技能包（createskill）

用户说「帮我做一个技能包 / 新建技能」时按这份说明执行，不要凭印象编格式。

## 一、包放哪

```
/storage/emulated/0/baicode/skill/<id>/
├── skill.json            唯一权威定义
├── README.md             用户看、模型 skill_read 看的用法
└── function/<fn>.js      每个函数一个模板体（后缀 js 只是沿用，不是 JS 语法）
```

先用 `skill_scaffold` 建目录（参数 name = 包 id，小写字母开头，可带数字下划线短横），再用 `write_file` 往里写三个文件。全部写完后告诉用户「去 设置 → 技能 点重新扫描」，不要自己假装已经生效。

## 二、skill.json 固定字段

```json
{
  "dsl": 1,
  "id": "files",
  "name": "文件查找",
  "desc": "一句话说明这个包能干什么",
  "trigger": ["找文件", "搜路径"],
  "funcs": [
    {
      "name": "searchpath",
      "kind": "cmd",
      "file": "searchpath.js",
      "desc": "按关键词在指定目录里找文件",
      "params": { "path": "^/[^\\s'\"`;|&$]{1,200}$", "kw": "^[\\w.-]{1,40}$" }
    }
  ]
}
```

- `dsl` 固定写 1。
- `id` 必须和目录名一致，全小写。
- `funcs[].name` 就是模型看到的工具名，全局唯一，建议 `<包id>_<动作>`。
- `params` 的值是**正则**，模型传进来的值必须能匹配上；留空串表示不限。
- 所有 params 都是必填，没有「可选参数」，需要可空就拆成两个函数。

## 三、模板体（function/<fn>.js）语法

只有两种 kind。

### kind = cmd

一行一条命令，逐行执行，任一行失败就停。插值用 `{参数名}`：

```
mkdir -p {path}/out && ls -la {path} | head -50
```

- `{path}` 会被替换成 **单引号包裹 + 内部转义**后的值，所以模板里不要再自己加引号。
- 需要输出字面量花括号时写 `{{` 和 `}}`，例如 `echo '{{"a":1}}'`。
- 禁止用 `$(...)`、反引号、`;`、`|` 去拼参数值，引擎不认，参数值里的特殊字符也不会被当命令执行。

### kind = http

第一行 `方法 URL`，随后每行 `Header: value`，空行之后是 body（可选）：

```
POST https://api.example.com/v1/query
Authorization: Bearer $secret.demo
Content-Type: application/json

{{"q":"{kw}","limit":10}}
```

- 方法只支持 GET / POST / PUT / PATCH / DELETE / HEAD。
- URL 必须以 http:// 或 https:// 开头，中间不能有空格；参数值里有空格就自己换成 `+`。
- body 里要写 JSON 时同样用 `{{ }}` 转义花括号。

## 四、密钥

不要在模板里写明文 token / 密码。密钥统一写成 `$secret.<名字>`，用户在 设置 → 技能 → 密钥 里填过一次即可。没配的密钥会让函数直接报「未配置」，这是预期行为。

## 五、引擎校验什么（写错会被拒绝执行，并带行列号）

1. `{x}` 里的 x 没在 params 声明 → 未知参数
2. 花括号不配对 → 报错，字面量请写 `{{ }}`
3. 参数名含空格、点、短横 → 非法参数名
4. 模板体为空 → 报错
5. http 首行不是「方法 + URL」或 header 行没有冒号 → 报错
6. 参数值里有换行 → 报错（防注入多条命令）
7. 传了 params 里没声明的参数 → 报错

## 六、做完的检查清单

- [ ] 目录名 = skill.json 里的 id
- [ ] 每个 funcs[].file 都在 function/ 下真实存在
- [ ] 模板体里出现的每个 `{xxx}` 都在 params 里有正则
- [ ] 需要密钥的地方写了 `$secret.xxx` 并在回复里告诉用户去配
- [ ] 提醒用户点「重新扫描技能包」，并说清怎么用一句话试

## 七、别做的事

- 不要为了「更灵活」引入 if / 循环 / 变量赋值：1.3.0 的 DSL 只有插值，逻辑请拆成多个函数。
- 不要写超过 3 层的目录跳转命令，模型和用户都难核对。
- 不要在一个 http 函数里拼两个请求，一个函数只发一次请求。
