一、它是什么，先把预期对齐
================================================================

这不是一个"聊天软件"，是一个跑在手机上的 Agent：
你说目标，它自己拆步骤、调工具、执行、把结果交回来。

- 模型是直连的：你填自己的 Base URL 和 Key，没有任何中转服务器。
- 会话、文件、密钥全部留在本机 SQLite，不上云。
- 工具是"真执行"：读文件、写文件、跑 shell、跑 Linux、点屏幕、
  开网页，都是真的动你的手机，不是演示。

所以第一件事不是激活，是理解权限：它是拿着你的权限在干活。


三档工作方式（同一个工具表，三条通道，随时切换）

普通用户
  需要什么：装完就有
  能干什么：对话、文件读写、exec_shell（应用身份）、
            无障碍截屏/点击/滑动/输入、联网工具
  限制：    碰不到系统级目录；Android/data 只能靠零宽路径碰运气

Shizuku
  需要什么：另装 Shizuku App 并启动服务（无线调试 / adb / root 三选一），
            再在 BaiAgent 里申请授权
  能干什么：Binder 桥接拿到 shell（UID 2000）能力——
            uiautomator dump、screencap、后台应用管理、深读 data
  说明：    不需要 Root，Android 11+ 体验最好

Root
  需要什么：设备真的已 root
  能干什么：su -c 直接执行，系统目录读写、静默装卸、全局操作
  说明：    工具内部优先走 su

三档不是互斥开关。切完下一次工具调用就生效，
工具弹窗里会标出这次实际走了哪条路。

二、装机与"激活"（首次启动 7 步）
================================================================

先把话说清楚：BaiAgent 没有激活码、没有卡密、不联网校验授权。
你付钱买的是分发，不是解锁——功能全开，自己编也行。
需要"激活"的只有两样东西：系统权限，和你自己的模型 Key。

系统要求：Android 7.0（API 24）及以上，targetSdk 34，
APK 内含 arm64-v8a 与 armeabi-v7a。


第 1 步  选界面语言
  默认跟随系统，中文/繁體中文/English/日本語/Français 五语。
  选好点「下一步」。

第 2 步  选择工作方式
  普通用户 / Shizuku / Root 三选一。
  - 手上没有 Shizuku 也没 root：选「普通用户」，后面随时能切。
  - 想用系统级能力：先装 Shizuku 并启动服务，再选 Shizuku，
    这里会直接弹授权请求。
  - 已 root：选 Root。
  这一步只是设定默认通道，之后在 设置 → 对话 → 权限工作方式 里还能改。

第 3 步  检查权限
  这里会列：
  - 存储权限（读写 /sdcard 必需）
  - 无障碍权限（屏幕操作、读控件树必需，点「激活无障碍」）
  - Shizuku 授权（上一步选了 Shizuku 才有）
  - 零宽路径探测（见下方说明，可选）
  能给的现在就给，跳过也不影响聊天，只是相关工具用不了。

    零宽路径是什么（可选）
    系统上有个路径变换漏洞，能让普通身份读写
    Android/data 与 Android/obb。首次启动实测通过时会问你要不要开。
    这属于漏洞利用：ROM 更新后可能失效，失败会直接报权限错误。
    之后要改：设置 → 对话 → 实验性功能 → 零宽路径 → 重新探测。

第 4 步  选择工作流（预设）
  四选一：通用助手 / 文件管理 / 设备运维 / 逆向分析。
  只影响 system prompt 的侧重，不改工具集。之后能改。

第 5 步  装运行环境（可选）
  内置 Ubuntu 24.04（proot + 自解包 rootfs），约 105MB，
  解包 1 ~ 3 分钟。装了才能在手机里 apt 装依赖、
  跑 gcc / node / rust / go，以及用 SSH 八件套。
  不想装就点「下一步」，之后随时在
  设置 → 扩展 → Linux 环境 里装。

  注意：只有 APK 里的 libproot.so 没解压出来时，
  界面才会提示环境异常。正常情况下 proot 已打进 APK，
  普通 / Shizuku / Root 三种方式都能起。

第 6 步  配置模型（这一步是真正的"激活"）
  三个字段全部非空才算配置完成：
  - 接口地址（Base URL）  例：https://api.openai.com/v1
  - 接口 Key              你的 key，只存本机
  - 模型名                例：gpt-4o / deepseek-chat / claude-3-7-sonnet
  任何 OpenAI 兼容接口都能接，包括中转站。

  填完还要勾"模型能力"（这一步错了会出各种怪问题）：
  - 图片输入（视觉）      不勾就看不到你发的图
  - 工具调用（function calling）  不勾它就只能聊天，不能干活
  - 推理 / 思考参数       不勾就不下发 reasoning_effort
  勾错了的后果：请求体里会被自动去掉，不会报 400，
  但能力真的没有了。以厂商文档为准。

第 7 步  同意用户协议
  同意才会继续。首次启动会问匿名使用统计，拒绝就不报，功能不受影响。

走完这 7 步，就能开始对话了。


================================================================
三、激活后的 5 分钟配置（强烈建议做完）
================================================================

设置页底部有六个 tab：模型 / 对话 / 外观 / 统计 / 扩展 / 关于。
右上角有搜索框，搜「主题」「Linux」「工具链」这类词能直接跳到对应项。

1) 工具权限        设置 → 扩展 → 工具权限
   每个工具有三种状态：每次确认 / 永久同意 / 永久拒绝。
   高危工具会单独标记。
   建议：先全部保持「每次确认」，用一周后再给自己常用的几个开永久同意。
   极简模式（见下）会自动只留五个工具。

2) 搜索（可选）    设置 → 扩展 → 搜索平台
   三家：Tavily / Bing / Google CSE，Key 自己填。
   不选平台，模型就拿不到 web_search 工具——这是设计如此，不是 bug。

3) 语音（可选）    设置 → 模型 → 语音识别 / 语音合成
   方式二选一：系统自带，或模型接口（OpenAI 兼容：
   识别 POST /audio/transcriptions，合成 POST /audio）。
   输入框左侧麦克风：点一下开始说话，说完自动填进输入框。

4) 数据加密        设置 → 关于 → 数据超强加密
   开启后凭据类数据（API Key、SSH 密码、MCP token 等）走三层密钥：
  Android Keystore 包裹 + HKDF 半密钥 + 数据密钥，AES-256-GCM 落盘。
   不开也能用，只是存明文 JSON（界面会直接标「未加密」）。

5) 隐私开关        设置 → 关于 → 隐私与安全
   - 数据输出脱敏：回复里出现 password / token 时打成掩码
     注意：开了这个会自动关掉流式输出，逐字显示没法事后过滤
   - 禁止截图与录屏：聊天页加系统级防截取标记，截出来是黑屏

6) 备份            设置 → 关于 → 备份与恢复
   一键导出成加密的 .baicodex（含数据库、全部设置、
   技能/角色/模型清单、头像）。换机、刷机、清数据前先备一份。
   导入后下一次启动自动替换。

四、日常怎么用
================================================================

发消息
  正常打字发送即可。Agent 在执行工具时：
  - 输入框右侧的红色方块 = 停止（会作废当前这一轮）
  - 发送过程中继续输入会自动排队，上一轮收工按序自动发出
  - 每条回答下面那行小字可配置显示：用量（token / tok/s）
    或请求信息（时间/供应商/模型/首响/总耗时），
    不想要就关：设置 → 对话 → 回复信息

@ 面板（这是效率核心，很多人不知道）
  输入框里打 @ 会弹出四组：
  - 技能     你写的提示词技能，选中会把技能正文带进这一轮
  - 工具     把某个工具的定义显式塞给模型
  - MCP      连上的 MCP 能力，显示为「MCP·服务·能力」
  - 工作区文件  直接引用绑定目录里的文件
  另有 @files 接路径，从 /sdcard 或工作区起点浏览目录、点文件填路径。
  适合：让模型"只看这一个文件"，比让它自己找省一大截上下文。

/ 快捷指令（点一条直接执行，内容不发给模型）
  /new       新会话
  /clear     清空当前会话消息（会话保留）
  /comp      把前面的历史压成摘要，省上下文
  /export    把当前会话导出成 Markdown，路径写进剪贴板
  /stat      跳到用量统计
  /persona   换智能体角色，下一句生效
  /voice     把当前草稿朗读一遍，再插回输入框

工作区（让相对路径有家）
  对话页右上角 </> 里绑定一个目录。绑定后：
  - 模型写的相对路径都落在这个目录，不会乱丢
  - @ 面板能列出这个目录里的文件
  - 每个会话一个独立目录，没被会话绑定的可在
    设置 → 对话 → 工作区信息 里一键清掉
  旧版散落在 baicode/ 下的工作区，那里有「一键迁移」。

运行模式（决定它能不能动手）        设置或对话页切换
  计划  只调研出方案，不改文件、不写盘。exec_shell 里
        rm/mv/cp/sed -i/git commit 这类写操作一律判死。
        适合："先看看，别乱动"。
  标准  全工具日常执行。
  代码  全工具，但把多步操作合并成脚本一次跑完，少来回。
  极简  只留文件四件套 + exec_shell，剥掉搜索/记忆/MCP。
        给弱模型兜底用。
  创造  标准之上允许改自己的提示词、技能包与配置。

分支与重发
  重新生成、编辑重发都不删旧回答，会多长出一支，
  聊天里用 ‹ 1/2 › 切换。一条消息只占一个位置。

记忆
  模型自己判断值得长期记住的偏好与结论，存进「永久记忆」，
  每轮随系统提示下发。
  查看/删除：设置 → 模型 → 记忆条目。
  对话里说「记住：我服务器是 1.2.3.4」它就会存。

上下文压缩
  设置 → 对话 → 上下文压缩：
  - 模型窗口（总上下文 token）
  - 压缩阈值（按窗口百分比折算字符数）
  - 压缩后保留最近条数
  - 总结补充要求（加在内置四段提示词之后，不替换）
  双阈值先到先压；省不到 15% 就不压；切点会退到
  「工具调用与其结果之间」的安全边界，不会切坏请求。
  短期操作：聊天里打 /comp，或点「立即总结」。

定时任务 / 通知触发        设置 → 扩展
  - 定时任务：到点发通知；勾了「到点自动执行」且模型空闲时会自己跑一轮。
    例：每天 08:30 汇总一次招聘信息。
  - 通知触发：某个应用来了带关键词的通知，就自动让我跑一轮。
    例：微信来了「老板」，就把消息整理成待办。
    需要通知使用权；规则可开可关。

五、深度玩法（按投入产出排序）
================================================================

1. MCP：把外部工具接进来        ← 单独一章，见第六部分

2. 内置 Linux 沙箱
   设置 → 扩展 → Linux 环境 → 安装 Ubuntu（约 105MB）。
   - 装完模型多了 linux_shell 工具，可 apt / gcc / node / cargo / go
   - /sdcard 与 /storage 直通，两边写文件互相看得见
   - 宿主侧（pm、am、uiautomator）仍用 exec_shell
   - 跑坏了点「重新解包」就是干净的
   - 起不来先点「自检」，失败原因会直接打出来
   典型用法：
   "在 Linux 里 pip install requests，写个脚本抓这个接口，
    结果存到 /sdcard/out.json"

3. SSH 八件套（装完 Linux 才有）
   连接 / 列目录 / 读文件 / 写文件 / 提权 / 执行 / 下载 / 上传：
   主机与凭据存一次复用；sudo 密码由工具喂给 sudo -S，
   不许也不必要写进命令行。
   典型用法：让它在服务器上拉代码、改配置、重启服务，全程手机指挥。

4. GitHub 技能包
   走 GitHub REST API：查仓库、issue/PR、读文件、新建或更新文件。
   token 走 $secret.github_token，不需要本地 git，不用装 gh。
   典型用法："把 issue 12 修了，开个 PR"。

5. 技能包（写自己的工具）      设置 → 扩展 → 技能包
   baicode/skill 下一包一目录，改完点「重新扫描」。
   校验不过的函数会列出来并且不会被调用。
   技能专区（提示词型技能）另有一处：设置 → 扩展 → 技能专区，
   写清触发场景 + 要走的命令 + 判断条件，启用后每轮请求都会带上。

6. 工作流                        设置 → 扩展 → 工作流
   多步任务串成一条流，每步跑一个分智能体，步骤之间不共享上下文；
   可存盘、可定时、失败能重试或跳过。
   适合固定套路：体检 → 抓日志 → 定位 → 出报告。

7. A2A                           设置 → 扩展 → A2A
   A2A 1.0 规范：本机既可当客户端调别的节点，也可开服务端收任务。
   开服务端后会给出 AgentCard 地址，填进别人的 A2A 客户端就能找到你。

8. 屏幕自动化（无需 Root，靠无障碍）
   工具 screen 支持：dump 节点树、截图、点击、长按、滑动、输入、
   按键、开应用、列应用。
   视觉 + 节点树双路：模型认不准控件会换一条路。
   多步任务时屏幕顶部会常驻操作胶囊，显示当前在干什么。

9. 内置浏览器（真 WebView，不是爬虫）
   browser：open 打开并回正文、text/links/find 取内容、
   click/input/scroll 按文字点按填表翻页、eval 直接跑 JS、
   back/forward/reload/url/close。
   要登录、要跑 JS 才出内容的页面走这条，比 http_fetch 强。

10. APK 逆向
   工具 apk：签名证书、二进制清单、权限与组件、dex 字符串、包内文件。
    典型用法："这个 APK 用了什么加固，签名是谁"。

11. 网络三件套（原生实现，比 shell 拼命令快）
    net_ping（TCP 建连计时）、net_curl（method/headers/body/
    timeout/maxBody）、net_page（抓网页转纯文本）。

12. 角色卡                          设置 → 扩展 → 智能体角色
    人设、适用场景、开场白、示例对话、后置指令、绑定模型。
    换角色等于换人格和说话方式。每个会话各自记角色。

13. 界面玩法                          设置 → 外观
    - 质感与玻璃：液态玻璃卡片 / 底栏、质感按钮；模糊强度 0 只留折射
    - 版面：消息圆角或胶囊、头像开关、字号整体缩放
    - 背景：纯色 / 柔光渐变 / 点阵 / 自定义壁纸
    - 桌宠：应用内常驻浮动形象，动画 30fps 节流；
      要全局展示得先给悬浮窗权限
    - 回复信息：Waifu 模式（回复按标点分句逐句发），
      开启后其下多一个「分句气泡动画增强」，
      新回复会像苹果 Messages 那样一条条弹出来
    - 预测性手势、粘贴长文本转文件（默认 3000 字阈值）、
      全屏输入入口，都在 设置 → 对话/外观 里

14. 插件广场                        左侧抽屉 → 插件广场
    浏览、安装、上传、版本历史、评论、点赞收藏。

15. 用量统计                        设置 → 统计
    总 token、柱状图、方格图、模型分类、月活跃；
    三项单价可填，直接算钱。

六、MCP 专章：把外部能力接进来
================================================================

MCP（Model Context Protocol）是标准协议，作用是：
让外部进程把它的能力"报"给你的 Agent，模型像调内置工具一样调它，
工具名形如  mcp_服务名_能力名。

入口：设置 → 扩展 → MCP 服务


支持两种类型

MCP（标准 JSON-RPC 2.0 over HTTP）
  端点一般以 /mcp 结尾。
  客户端行为（当前实现）：
  - initialize 握手（protocolVersion 2025-06-18，clientInfo BaiAgent）
  - 记 Mcp-Session-Id 并回传
  - 发 notifications/initialized
  - tools/list 拉能力、tools/call 调能力
  - Accept: application/json, text/event-stream —— SSE 响应也认
  - 非本机地址可填 Token，走 Authorization: Bearer
  - 连接超时 10s，读超时 120s

REST 桥（termux-mcp 老接口）
  能力清单来自 GET /tools（OpenAI function 结构）；
  调用只支持 POST /run，参数 cmd（或 command）+ timeout，
  也就是"把参数当命令执行"。
  其它能力只能当清单看，点下去会提示改用 run。


加一个服务的步骤

1. 设置 → 扩展 → MCP 服务 → 新增服务
2. 填：名称 / 地址 / 类型（MCP 或 REST 桥）/ Token（可选）
3. 点「测试连接」，成功会显示拿到几项能力
4. 保存后该服务出现在列表里，右侧可刷新、编辑
5. 拉到的能力自动并入工具表，同时出现在输入框 @ 面板的 MCP 组里
   模型也可以自己挑着调，不用你手动点名


Termux 里的实操（最常见场景）

  # 在 Termux 里
  pkg install termux-mcp
  termux-mcp          # 默认起在 127.0.0.1

  # BaiAgent 里新增服务
  名称：Termux
  类型：MCP
  地址：http://127.0.0.1:8081/mcp
  如果用的是老的 termux-mcp REST 桥：
  类型：REST 桥
  地址：http://127.0.0.1:8080

接上之后能干什么：让模型在 Termux 环境里执行命令、
取 Termux 侧的设备信息、调 Termux:API 的那批能力。
两个 App 同在手机上，走 127.0.0.1 不经过外网。


排错对照

  连接失败：HTTP 401 / 403
    → 填了 Token 但不是这个服务的鉴权方式，或服务端要的是别的头

  连接失败：Connection refused / timed out
    → 服务没起，或端口写错，或不是同一台机器。
      远程地址要确认手机能访问到（内网 IP、端口放行）

  「服务没有返回任何能力」
    → tools/list 返回空。多数是第一次握手没带 session，
      点一次「刷新」重来；仍为空就是服务端真没注册工具

  响应里没有 id=N 的结果
    → 服务端返回的 JSON-RPC 结构不标准（id 对不上）。
      换标准实现，或用 REST 桥

  调用后一直转圈
    → 服务挂在一条不关闭的 SSE 流上。当前实现对通知类请求
      不读响应体、对 SSE 只读到目标帧即断开，正常不会卡；
      卡住说明服务端连 tools/call 都推流，换服务或改桥

  能力拉到了但模型不调
    → 看 设置 → 扩展 → 工具权限 里该 MCP 能力是不是被设成「拒绝」；
      也检查当前运行模式是不是极简（极简会剥掉 MCP）

使用建议
  - MCP 能力是"外挂"，出错排查优先怀疑外部服务，不是 App
  - 服务越多，工具表越长，模型选错概率越高：
    不常用的服务在列表里关掉，或只在需要时刷新
  - 只想用某个能力时，@ 面板点名它，比让它自己挑稳


================================================================
七、常见问题与排错
================================================================

Q: 需要 Root 吗？
A: 不需要。普通身份能用绝大部分功能；系统级 shell 挂 Shizuku；
   改系统目录才要 Root。

Q: 真的免费吗？有激活码吗？
A: GPL-3.0 开源，无激活码、无内购、无次数限制，可自己编译。

Q: 数据上传吗？
A: 不上传。只有你配的模型接口、你主动用的搜索/12306 会出网。

Q: Shizuku 授权点不动 / 没弹窗
A: 三种情况对应三句话：
   - 「拒绝且不再询问」→ 打开 Shizuku → 授权应用 → 找到 BaiAgent 手动开
   - 「服务没在运行」→ 先打开 Shizuku 把服务启动
   - 「等不到回应」→ 看 Shizuku 弹窗是不是被别的窗口挡住

Q: Shizuku 明明授权了，工具还是说连不上
A: 连接失败后有 60 秒静默期，别连着猛点，等一分钟再试。
   仍然不行就杀掉 App 重开——连接状态机是进程级的。

Q: 无障碍老是掉
A: 打开 设置 → 对话 里的「Shizuku 自动补无障碍」，
   每次回到前台会自动写回无障碍。这是 MIUI/HyperOS 之类
   杀服务最常见的问题。

Q: 工具调用直接被拒
A: 两处都可能拦：设置 → 对话 → 权限工作方式（当前档位缺权限），
   或 设置 → 扩展 → 工具权限（这条被设成拒绝）。
   界面会写清楚缺哪个权限，缺的直接点「申请权限」。

Q: 计划模式下它什么都不干
A: 这是设计。计划模式禁掉所有落地改动；要动手切到标准/代码模式。

Q: 内置 Linux 起不来
A: 设置 → 扩展 → Linux 环境 → 自检，会打出失败原因；
   常见是 rootfs 解包不完整，点「重新解包」。
   再不行就「重装依赖」。

Q: 零宽路径失效了
A: 系统更新修掉了。设置 → 对话 → 实验性功能 → 零宽路径 →
   重新探测。不支持就走 Shizuku/Root。

Q: 更新点下载一直不动
A: 直链落在 GitHub Releases，部分地区会 504/超时。
   弹窗里若同时有「打开下载页」，走浏览器下载即可；
   也可以直接从 releases 页面拿 APK 覆盖安装（同签名可直接升级）。

Q: 换手机怎么搬数据
A: 设置 → 关于 → 备份与恢复 → 导出备份，把 .baicodex 拷过去，
   新机导入后重启 App。密钥不在备份里，注意别丢文件本身。

Q: 长会话很卡 / 疯狂滚动
A: 已经是 1.14.1 的行为：进会话只跳底一次，流式贴底节流到 120ms。
   如果还卡，把 设置 → 外观 → 质感与玻璃 的模糊强度调到 0，
   液态质感来自折射，不影响观感，但省掉离屏合成。

八、一页速查
================================================================

想让它干活         说清楚目标 + 给路径，别只说"帮我看看"
怕它乱动           切「计划」模式
只想让它读某个文件  @ 面板引用文件，或 @files 接路径
省 token            /comp 立即压缩；@ 精准引用；关掉不看的注入项
重复性的活         写成技能或工作流，别每次重复解释
固定环境           绑定工作区，相对路径才有意义
外部能力            MCP；系统级命令 Shizuku/Root；Linux 里跑重活
安全                数据超强加密 + 输出脱敏 + 禁截图，三件都在
出问题              设置 → 关于 → 意见反馈；或 设置 → 扩展 → 工具权限
                    先把「每次确认」打开，看清它到底要干什么
